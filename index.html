Installation manuelle

Installation manuelle (Linux et macOS)

  1. Installe Java 21 et lance Minecraft 1.21.11 une fois.
  2. Installe Fabric pour Minecraft 1.21.11 avec l’installateur officiel sur fabricmc.net.
  3. Mets deux fichiers dans le dossier mods : Fabric API et vortex-client.jar. Sous Linux, c’est ~/.minecraft/mods. Sous macOS, c’est ~/Library/Application Support/minecraft/mods.
  4. Lance le profil Fabric et appuie sur Shift droit en jeu pour ouvrir le menu.
