3

Lance la partie

Choisis le profil dans le launcher Minecraft, joue, puis appuie sur Shift droit.

Installation manuelle

Pour Linux et macOS.

  1. Installe Java 21 et lance Minecraft 1.21.11 une fois.
  2. Installe Fabric pour Minecraft 1.21.11 avec l’installateur officiel sur fabricmc.net.
  3. Mets deux fichiers dans le dossier mods : Fabric API et vortex-client.jar. Sous Linux : ~/.minecraft/mods. Sous macOS : ~/Library/Application Support/minecraft/mods.
  4. Lance le profil Fabric et appuie sur Shift droit en jeu.

Questions fréquentes

Quelles versions de Minecraft sont prises en charge ?

Pour l’instant, Minecraft 1.21.11 avec Fabric.

Comment ouvrir le menu en jeu ?

Appuie sur Shift droit. La touche se change dans le launcher.

Windows affiche un avertissement au lancement. Pourquoi ?

Le programme n’est pas signé numériquement, donc Windows le signale comme inconnu. Ne l’ouvre que si tu l’as téléchargé depuis cette page.

Puis-je l’utiliser sur n’importe quel serveur ?

Chaque serveur a son propre règlement et peut interdire certains modules. Lis-le avant d’en activer.

Comment le désinstaller ?

Supprime le .exe et le dossier .vortex situé dans %APPDATA%.
